# **Terraform y AWS**

Este repositorio contiene tutoriales de como aplicar los principios de IaC utilizando Terraform y AWS.

## Proyectos

1. iam: creación de usuario.
2. iam_s3: fundamentos de almancenamiento (centralizar fuentes de datos).
